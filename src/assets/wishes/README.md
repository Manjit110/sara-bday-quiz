# Photos for the Wishes page

Drop a photo in here named after the person's `id` from
[`src/wishesData.js`](../../wishesData.js), e.g.:

```
nitpreet.jpg
ritika.jpg
arpit.png
akansha.jpg
sarvesh.jpg
anisha.jpg
zalak.jpg
bhumi.jpg
karan.jpg
piyush.jpg
manish.jpg
```

- Filename (without extension) must match the `id` exactly, lowercase.
- `.jpg`, `.jpeg`, `.png`, `.webp`, and `.avif` all work.
- No code changes needed — just add the file, commit, and push. The next
  deploy will automatically pick it up and show the real photo instead of
  the placeholder initial.
- Anyone without a photo file here just gets a nice colored initial avatar
  on their polaroid — totally fine to leave some/all of these missing.
